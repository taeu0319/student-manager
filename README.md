# 📊 학생 성적 관리 시스템 (Student Grade Management System)

C언어의 핵심 자료구조인 **구조체(Struct)와 배열(Array)**을 활용하여 구현한 콘솔 기반(CLI) 성적 관리 프로그램입니다. 

## 🚀 프로젝트 개요
* **언어:** C
* **환경:** GCC 컴파일러 / 터미널(Console) 환경
* **목적:** C언어 기초 문법(조건문, 반복문, 형변환) 및 메모리 구조체 활용 능력 학습

## ✨ 주요 기능 (Features)
1. **학생 데이터 추가:** 학생의 이름과 점수를 입력받아 메모리에 안전하게 누적 저장합니다. (최대 100명)
2. **전체 조회 및 평균 산출:** 등록된 전체 학생의 성적 목록을 출력하고, 누적된 점수를 바탕으로 전체 평균을 소수점 둘째 자리까지 정확하게 계산합니다.
3. **안전한 예외 처리:** 등록된 데이터가 없을 경우 평균 계산(0으로 나누기)을 방지하고 안내 메시지를 출력합니다.

터미널에서 아래 명령어를 입력하여 코드를 컴파일합니다.
```bash
gcc -o grade_manager main.c
